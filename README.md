# Zelo Segurança e Automação

Site institucional da Zelo Segurança e Automação.

## Como visualizar
Abra `index.html` no navegador. Para desenvolvimento local, você também pode iniciar um servidor simples:

```bash
python -m http.server 8000
```

Depois acesse http://localhost:8000.

## Publicação no GitHub Pages
1. Envie os arquivos deste projeto para um repositório GitHub.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
